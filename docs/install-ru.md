# CoinsPay для OpenCart — установка

Плагин принимает оплату криптовалютой через CoinsPay: покупатель выбирает монету и сеть на
странице оплаты CoinsPay, а заказ сам получает статус, который вы выбрали для каждого события
счёта.

Нужен аккаунт CoinsPay с магазином. Ключ API и вебхук настраиваются в кабинете CoinsPay.

## Какой архив ставить

| OpenCart | Архив | Как установить |
|---|---|---|
| 1.5.x | `coinspay-opencart-1.5.zip` | скопировать содержимое папки `upload/` в корень магазина по FTP |
| 2.0 – 2.2 | `coinspay-opencart-2.0-2.2.ocmod.zip` | скопировать `upload/` по FTP (установщик расширений 2.x требует настроенный FTP) |
| 2.3 | `coinspay-opencart-2.3.ocmod.zip` | скопировать `upload/` по FTP или «Расширения → Установщик», если FTP настроен |
| 3.0.x, ocStore 3.0 | `coinspay-opencart-3.0.ocmod.zip` | «Расширения → Установщик» → загрузить архив |
| 4.0 – 4.1 | `coinspay.ocmod.zip` | «Расширения → Установщик» → загрузить архив → «Установить». Имя архива менять нельзя: из него OpenCart делает папку расширения |

## Включение

1. «Расширения → Расширения → Оплата» (в 1.5 и 2.0–2.2 — «Расширения → Оплата») → CoinsPay →
   «Установить», затем «Изменить».
2. В кабинете CoinsPay откройте магазин:
   - в разделе «Ключи API» выпустите ключ с доступом «Только счета» и вставьте его в поле
     «Ключ API». Плагину больше не нужно, а вывести деньги таким ключом нельзя, даже если
     его прочитает кто-то из пользователей админки;
   - поле «Адрес API» оставьте пустым: тогда плагин использует `https://coinspay.app/api/v1`;
   - в разделе «Вебхук» укажите адрес, который показывает плагин, сохраните и скопируйте
     секрет `whsec_…` в поле «Секрет вебхука».
3. Нажмите «Проверить подключение», затем в кабинете — «Отправить тестовое событие»: в плагине
   появится время, когда событие дошло.
4. На вкладке «Статусы заказа» выберите статус для каждого события счёта. В списках есть и ваши
   собственные статусы. «Не менять статус» оставляет статус как есть, а комментарий с суммами,
   монетами и хешами транзакций всё равно пишется в историю заказа.
5. Включите способ оплаты и сохраните.

## Тестовый режим

С ключом `cpk_test_` счета оплачиваются кнопкой на странице оплаты, монеты не переводятся. По
умолчанию способ оплаты с тестовым ключом виден только тестовому покупателю: откройте магазин
ссылкой «Открыть магазин как тестовый покупатель» из настроек (ссылка действует сутки в том
браузере, где её открыли). Тестовая оплата закрывает только заказы тестового покупателя.

## Если вебхуки не доходят

Плагин сам спрашивает CoinsPay об открытых счетах:
- со страниц магазина — не чаще раза в 5 минут (OpenCart 2.2 и новее);
- при открытии «Адреса для cron» из настроек. Для магазина с небольшим числом посетителей, а
  также для OpenCart 1.5 и 2.0–2.1 добавьте этот адрес в cron хостинга раз в 5 минут.

В режиме обслуживания OpenCart 2.3 и 4.x не принимает вебхуки — после выхода из режима опрос
догонит изменения.

## Что стоит знать

- Магазин отменил заказ (статус из «Статусов отмены заказа») — плагин отменяет и открытый счёт,
  оплатить его больше нельзя. В OpenCart 1.5 это делает опрос.
- Сумма или валюта оплаченного счёта не совпадает с заказом, оплачен заказ, который отменил
  магазин, — статус события «требует решения» и комментарий с подробностями.
- CoinsPay не принимает валюту покупателя — счёт выставляется в основной валюте магазина.
- OpenCart 1.5 списывает остаток при подтверждении заказа и не возвращает его при отмене — так
  он работает со всеми способами оплаты.
- Известные ошибки самого OpenCart, которые мешают любым способам оплаты:
  - 4.0.0.0 в корне сайта теряет сессию покупателя (путь cookie `//`) — обновитесь до 4.0.2.x+;
  - 4.0.2.x падает на письме о заказе без доставки при выключенном выводе ошибок;
  - 2.2.0.0 выводит предупреждения прямо в страницы — выключите `error_display` в
    `system/config/default.php`;
  - 4.0.1.x иногда теряет выбранный способ оплаты при оформлении заказа — обновитесь до 4.0.2.x+.
